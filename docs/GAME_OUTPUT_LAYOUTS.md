# Organização por jogo

As regras de entrega são específicas de cada jogo. O usuário definirá o
layout dos outros jogos conforme forem sendo trabalhados.

## State of Decay

- Dublagem completa: manter `_saida_final` no projeto e copiar seu conteúdo
  para `uploads/State of Decay/<pasta original do personagem>/`.
- Correções: manter `_correcoes` e atualizar também o arquivo na mesma pasta
  de personagem dentro de `State of Decay`.
- Reutilizar a pasta do jogo e preservar nomes, extensões e personagens.
- O nome original da pasta prevalece sobre nomes internos do projeto.
- SAM pertence a State of Decay.
- Essa pasta é uma entrega para copiar; não é a instalação do jogo.

Os outros jogos mantêm o comportamento anterior até receberem sua própria
regra. Não extrapolar a estrutura de State of Decay para outro jogo.
